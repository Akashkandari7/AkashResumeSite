# akash-portfolio

Personal portfolio of Akash Kandari. Plain HTML, CSS and JavaScript, no build step.

- `index.html`, `style.css`, `script.js`
- `assets/shots/` — Dragon Pit screenshots
- `assets/photo.jpg` — profile photo (the initials show until it exists)
- `assets/AkashKandari_Resume.pdf`

Run locally: `python -m http.server` and open http://localhost:8000.
Deployed on Vercel as a static site.
